	WHAT IS A DATABASE ?

	IT IS A REPOSITORY / CONTAINER / STOREHOUSE THAT IS USED TO
	STORE DATA IN A STURUCTURED FORMAT ( DB SCHEMA ) TO FACILITATE
	CRUD OPERATION BY ANY TECHNOLOGY.

	IT CAN CONTAIN ROW OF RECORDS IN A TABLE AND THERE IS EVERY POSSIBILITY
	OF RELATIONSHIPS AMONG TABLES TO ENSURE CONSISTENCY ( ACCURACY OF 	DATA ) AND DATA REDUNDANCY.


	WHAT IS THE LANGUAGE OR MEDIUM THAT ANY RDBMS CAN UNDERSTAND ?
		IT IS SQL ( SEKEL ) DIVIDED INTO THE FOLLOWING CATEGORIES


			DDL ( DATA DEFINITION LANG )

				CREATE / ALTER / DROP

			DML ( DATA MANIPULATION LANG ) WIDELY ABUSED

				INSERT / UPDATE / DELETE

			DQL ( DATA QUERY OR RETRIEVAL LANG )

				SELECT    --- WIDELY USED FOR REPORT 							GENERATION

			DCL

				REVOKE / GRANT

			TCL

				COMMIT / ROLLBACK




				JDBC

	IT IS A JAVA TECHNOLOGY THAT ALLOWS INTERACTION WITH ANY RDBMS
	SEAMLESSLY ( EFFORTLESS )

	JDBC IS ALL ABOUT INTERFACES ( MEANS A CONTRACT ) TO BE IMPLEMENTED
	BY THE UNDERLYING DATABASES.

	POPULAR RDBMS SUPPORTED BY JDBC ARE THE FOLLOWING :

		SQL SERVER
		ORACLE SERVER
		MYSQL
		POSTGRE
		SYBASE
		INGRES

		steps in developing a JDBC program


		1. get THE CONNECTION TO THE DB SERVER


			DM     DS      CPDS      JNDI
